# DataEX-Sc V261013 更新说明

**版本**：DataEX-Sc - Scatter Plot Data Extractor **V261013**
**更新日期**：2026-10-13

本版本主要增加 **组合图分割** 与 **图片类别人工审核**。

---

## 本次更新

1. **组合图智能分割**可自动识别多子图布局（左右/上下对切、网格、嵌套 inset 等），也可在图上手动画框。Extract 侧栏新增 **Subplots**。
2. **按子图提取**批量 / 自动提取默认对每个子图分别做图例检测与数据提取，再合并结果，避免整图一条流水线串点、漏点。界面可用绿条在多个子图间切换查看。
3. 顶部新增 **Scatter Review（人工分类）**：Y = 散点，N = 非散点（软删除），S = 跳过，U = 撤销，便于快速筛图。
