# DataEX-Sc V260919 更新说明

**版本**：DataEX-Sc - Scatter Plot Data Extractor **V260919**  
**更新日期**：2026-09-19

本版本只改 **Data Visualization** 的坐标轴显示，提取出的数据不变。

---

## 本次更新

1. **坐标轴默认贴合数据**  
   以前横纵轴往往从 0 画起。数据如果只落在远离 0 的一小段，点会挤在角落。现在打开即可看清这一段。

2. **可切换查看范围**  
   图表上方 **Axis range**：
   - **Fit data**（默认）：贴合当前散点
   - **Include 0**：线性轴包含原点
   - **Anchors**：按校准锚点的数值范围显示，便于对照原图刻度

3. **对数轴**  
   不再被拉成整段十倍区间。对数轴不能包含 0；小于等于 0 的点不会画出，图旁会提示。
